# COR3 Agent Guide

面向玩家和浏览器 Agent 的 COR3 Deployment 社区攻略。覆盖实测剧情路线、市场委托、解密小游戏和掉线排查。任务名保留游戏原文，便于在界面里定位。

## 让 Agent 使用

把本仓库的 GitHub 地址和下列指令交给能读取网页或仓库的 Agent。已经克隆仓库时，可以在项目目录直接使用。

```text
先读 AGENTS.md，再按 guide.json 查找我当前 COR3 任务和对应攻略。
根据我已登录的游戏画面确认可推进的步骤、装备要求和倒计时。
在我授权的范围内使用游戏界面，完成后核对任务进度和奖励。
遇到阻塞时，报告界面显示的原因和可验证的下一步。
每轮结束或等待刷新前，保存进度，关闭你操控的 COR3 标签页，并检查标签列表确认已关闭。
```

读取攻略只需访问仓库。操作游戏需要 Agent 获准使用玩家自己的浏览器和游戏会话。
