# 委托、装备与中转

## Market Job

1. 从 Network Map 选 Home Server，进入 `Market > Job`（市场 > 委托）。
2. 接取前核对目标、剩余时间、押金、失败扣除和工具强度。优先做当前装备可以完成且能在刷新前交付的委托。
3. 有 `Task Access` 时优先使用授予的任务权限。实测同一节点的两笔 Access Grant 委托，可以在同一个游戏内 SAI 会话做完，再逐笔领奖。文件解密类委托从游戏桌面的 Downloads 打开目标，核对文件标题后开始。
4. 做完回 `Market > Job`。中文版的委托卡显示「可完成」时，点「阅读更多」，再点目标文件旁的「信息」，在委托弹窗里选「完成」。看到「任务已完成」后核对到账，把 CR 奖励、退回的押金和 Market Rep 分开看。

| 界面任务名 | 已验证动作 | 结算观察 |
| --- | --- | --- |
| File Decryption | 打开 Downloads 中与委托一致的加密文件，完成三轮图案 | 多次显示 838 CR、退回 126 CR 押金、151 Market Rep |
| Data Download | 用授予的 Task Access 下载委托目标文件 | 一次显示 856 CR、退回 129 CR 押金、155 Market Rep |
| Log Deletion | 在游戏内 Logs 核对已接受委托的目标后完成操作 | 一次显示 721 CR、退回 109 CR 押金、130 Market Rep |
| File Elimination | 在游戏内 SAI 的 `Files` 删除委托指定文件 | 一次显示 721 CR、退回 109 CR 押金 |
| IP Cleanup / IP Injection | 在游戏内 SAI 的「中转访问」按委托逐条移除或加入指定项目 | Access Acquisition 档实测各为 1,221 CR |
| Data Upload | 从目标节点的 `Files` 点上传箭头，在游戏内选择器中打开 `Downloads`，选中委托文件并点「上传」 | 实测文件出现在节点列表，领取 1,113 CR、退回 167 CR 押金 |
| Log Download | 对照委托目标和当前可用权限。遇到需要通过的关卡时，先核对工具强度 | 核对委托奖励和最终领取状态 |

以上金额只对应观察到的委托档位。领取按钮和到账由当前合约决定。

刚打开加密文件时可能先显示「正在加载文件分析…」。等加密强度和解密强度出现后再判断能否开题。快速切换多个文件曾触发游戏的请求频率提示，按提示稍等。中转访问有多条待移除时，在每次确认后等对应行消失，再处理下一条。

相同奖励的解密委托也可能有不同条款。实测均奖励 838 CR 的委托，有的收 126 CR 押金，有的规定失败扣 46 Market Rep。签署时核对弹窗。

`Access Acquisition` 委托也能使用游戏里已有的「通过工具授予」访问。实测在两个 CEDRT 节点选择该访问卡并登录后，可查阅委托需要的「中转访问」和 `Files`。

## Loadout and power

- 用同一窗口的装备强度对照文件加密等级或 SAI 防御。`RM7-S4L3` 曾显示 13 点防御且无 Task Access。使用 12 点的 Porter-lite 时，地图能连通，委托仍无法完成。
- `RM7-S4L1` 的 SAI 显示 12 点防御时，实测 12 点的 `Porter-lite r4` 可开启并通过三轮图案挑战。登录后按委托处理「中转访问」，回市场确认 IP Injection 结算。一次奖励为 1,274 CR。
- `RM7-N1L1` 的一次 Access Acquisition 委托也遇到 13 点防御。连接 `RM7-N2L2` 后，在游戏地图输入 `855.529.4.1` 并按 Enter 即可找到它。接单前在 SAI 核对有效访问和兼容工具。
- UNO 6.651 的一次成功配置显示 12.7 GHz、总负载 2.0 / 2.0 kW。相同 GPU 和电源搭配下，单装 `Porter-lite r4` 显示 12 点强度，单装 `Cypher+ v1.4` 显示 15 点解密能力。根据任务切换。
- `Loadout > 信息` 可查看软件兼容的游戏服务器类型。`Porter-lite r4` 的软件信息列出 `CEDRT public` 和 `CEDRT private`，可据此排除 `USOL public` 和 `EMERMODE`。
- 在 Loadout 先关机，卸下旧工具，再装所需工具并开机。返回后重新打开目标窗，按新显示的强度判断能否做任务。
- 电源按钮文字可能一直显示 `POWER ON`。点击一次后，通过「系统已关闭」或「系统已启动」通知确认实际电源状态，再更换设备。
- 开机时可以点硬件旁的「更换」，查看已拥有的零件和当前项。先核对有没有合适的备件，再关机换装。
- `Loadout > 帮助 > 软件参数` 说明基础消耗和最低性能所需的资源都要满足。选购软件时对照商品的最低值和现有硬件。装机后以实际显示的强度为准。

## Stash sale quotes

市场的「出售」显示暂无物品时，可以到桌面底栏的储藏室里查报价。选中一件普通补给，在「检视」点「出售」。实测先弹出报价，可以在确认前取消。一次检查中，`Water vial` 和 `Kosmonavt Energy Bar` 分别报价 744 CR 和 1,562 CR。剧情物品保留在背包，成交以确认界面的状态和余额变化为准。

## Transit access

游戏地图提示无路由时，先查对应中转权限。一次购买 `RM7-E1SCP Transit` 的 4 小时 access 花费 575 CR，生效后连接 `RM7-E1SCP`，实际到达 `RM7-S4L4`、`RM7-S4L1` 和 `RM7-S4WCP` 所在区域。在游戏地图上，`855.529.2.12` 可用于继续找出 `RM7-S4L2` 和 `RM7-S4L3`。需要做的内容较集中时再买限时权限，先核对报价和有效时间。

实测先连上 `RM7-E1SCP` 仍可能显示到南区无路由。中转激活后重新连接目标，再查 SAI 列出的有效访问。`RM7-S4L4` 这次保留了先前的工具访问，装着解密模块也可用这项访问进入。

如果 SAI 的「登录」按钮呈灰色，先选中「有效访问」栏里已有的访问卡。实测在 `RM7-N2ECP` 选中先前通过工具获得的访问后即可登录。

## Daily Ops

从桌面底栏打开 `Game Center > 日常行动`。`System Log Integrity` 和 `Signal Decode` 都有实测领奖，分别显示 300 CR。音频信号用当前界面的长短信号逐位识别。完成后核对「所有任务已完成」和当日奖励，按该面板的倒计时等下一批。已完成的行动可能仍显示「重玩」。

刚打开面板时，曾短暂出现「新任务已开放」和 `00h 00m 00s`。等当日进度和奖励加载后，再按实际倒计时安排续玩。

### 系统日志完整性

1. 点 `Start`，对照同批条目的时间、事件名及 `/sector`、`/status` 字段，选出两条格式异常，再点 `Confirm Selection`。
2. 在 `Format Revision` 逐条用 `Fix Error` 选择错误原因。实测过漏写 `/sector` 和事件名拼错两类。界面会按所选原因生成修正后的条目。
3. 点 `Confirm Fixes`，核对修正结果，再点 `Run Re-scan`。实测显示 `Clean` 后，日常页标记完成，余额自动增加 300 CR。
