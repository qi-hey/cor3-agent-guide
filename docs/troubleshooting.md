# 问题排查

## Disconnect and retry

同一游戏账号的多个标签会互相替换会话。实测原页仍在时，第二页多次显示已连接，随后又断开。续玩时保留一个游戏页。若浏览器预览仍由上一轮任务控制，先在原页恢复操作权。

掉线时在原页点 `Retry`。短暂显示「已连接」后仍可能掉线，等市场和目标文件稳定加载后再开始计时谜题。计时中途掉线时重新核对剩余时间和游戏状态。

单个既有页面普通刷新后曾保留进度，也曾让新解锁的对话显示出来。`Restore` 的用途是重置存档。

预览服务重启后，旧标签可能从列表消失。实测确认列表为空后，使用原登录配置打开一个游戏页，已签署的委托、押金和已领取的奖励均保留。

### 任务结束后关闭标签页

1. 本轮做完、停止或暂停等刷新时，先确认已完成事项和奖励到账，记录未完成事项和下次刷新时间。
2. 由 Agent 使用浏览器的关闭标签页操作，关闭本轮操控的 COR3 标签。重新查看标签列表，确认该页已经消失。若关闭失败，先核对列表，在原页恢复操作权后再试。仍关不上时，如实记录错误和标签状态。
3. 下次续玩先检查标签列表。有 COR3 页就复用，确认没有游戏页后再打开一个。

## Map search and loading

- 在 Network Map 展开搜索，填完整的游戏内地址后按 Enter。停在输入状态只会过滤已发现的节点。
- 已发现的节点可以按名称搜索定位。地图节点挡住搜索图标中间时，试点图标上缘的露出部分。
- 地图显示连接成功后可继续寻找下一个中转点。查看某个节点的文件时，另行检查 SAI 访问状态。
- Act 3 节点用地图查找。游戏内 Terminal 的 `connect` 在该场景会显示 `Invalid command`。
- Files 和 Logs 切换后可能先显示空列表，等待文件数据加载。NPC 消息曾在约 5–6 秒后才出现，先等回复再重复操作。

## Market entry

Home Server 显示在线却没有「市场」时，在当前游戏地图选一个可直连的已知节点，例如 `RM7-E1L3`，点「连接」。看到该节点的「断开连接」后，重新选 Home Server，实测「市场」入口恢复。

## Claim and refresh

谜题通过后到委托页确认是否可领取，领取后查看变更。实测解密结束后，委托卡短暂显示「进行中」，随后才变成「可完成」。先给游戏状态留出同步时间，再重新核对。委托超时可能转成 `FAILED` 或过期，继续前核对最新可接列表。新委托出现的时间以市场自己的倒计时为准。

签署或领取弹窗持续转圈时，实测在同一标签普通刷新后可恢复。回「委托」对照目标、卡片状态和余额。确认仍是可签署或可领取时，再点一次并核对结果。

## Account discount

Fragmentary Order 在 2026 年 11 月 17 日公告，Prime Batch 结算会同步 COR3 等级，登录关联账号后自动应用符合条件的等级折扣。[Fragmentary Order 折扣公告](https://x.com/fragorder/status/2122728823322214613)

官网预购的 Details 页提示使用 COR3 绑定邮箱，以便下一步显示账号福利。已实测到 Details 页。结算价格由账号持有人核对。

游戏内 `Information note > Ranks` 列有 Early Deployment 优先级和等级要求。实测面板显示 Pathfinder 可在 Renown 13 时自动获得，也可通过剧情推进获得。
